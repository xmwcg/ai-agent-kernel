# 企业 AI Agent 起步包 — 产品说明

> 基于 `ai-agent-kernel` 私有化 Agent 内核，打磨而成的「企业 AI Agent 起步包 / 定制交付底座」。
> 定位：让企业 **私有部署** 一个可控、可审计、可多租户的 AI Agent 内核，作为内部智能体平台底座。

## 一句话定位

**一套可私有部署、带 UI 与监控的 AI Agent 内核，企业拿去即可当内部智能体平台用，或作为定制交付底座。**

## 核心能力

| 能力 | 说明 |
|------|------|
| 私有化内核 | 开源 MIT，部署在企业自有服务器/内网，数据不出域 |
| 6 个基础工具 | 读/写文件、安全 exec、Python 执行、联网搜索/抓取 |
| LLM function-calling | 模型自主决策调用工具，非手动触发 |
| 多智能体 | Coordinator 路由到 研究员/程序员/写手/审核员 |
| 企业鉴权 | 管理员令牌 + 租户 API Key（逻辑隔离） |
| 用量监控 | Token 消耗、请求数、成功率、按租户统计 |
| 管理后台 | `/admin` 查看用量、管理租户密钥 |
| 品牌化 | 企业名称 / Logo 可配 |
| 一键部署 | `docker compose up` 即起（API + 前端同源单进程） |

## 市场差异化

- **对比 `obra/superpoints`（198k★）**：superpowers 是「方法论框架」，偏重工程纪律；本包是 **可运行产品**，且更轻、可私有部署、中文交付。
- **对比通用 Agent 平台（SaaS）**：本包 **数据不出企业**，无按量付费锁定，适合金融/政企等合规场景。
- **对比 LangChain 脚手架**：零重依赖、单进程部署、开箱即用。

## 适用客户

- 想自建内部 AI 助手 / 知识助手的企业 IT 部门
- 需要 AI Agent 能力但要求数据私有化的行业（金融、制造、政企）
- AI 服务商：把本包作为定制交付底座，叠加行业技能快速交付
