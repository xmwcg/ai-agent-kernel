## 我们做什么

**企业 AI Agent 起步包** = 一套可私有部署、带 UI 与监控的开源 AI Agent 内核，
企业拿去即可当**内部智能体平台**用，或作为**定制交付底座**。

- 开源 MIT，数据不出企业
- 开箱即用：聊天 UI + 工具调用 + 多智能体
- 企业管理：鉴权、多租户、用量监控、后台

## 解决什么痛点

| 痛点 | 我们的答案 |
|------|-----------|
| 用公有云 Agent，数据外泄风险 | 私有部署，数据不出域 |
| 从零搭 Agent 周期长、门槛高 | `docker compose up` 即起 |
| 模型不会自己用工具 | 内置 function-calling，自动调工具 |
| 多团队共用无隔离无计量 | 租户密钥 + 用量监控 |

## 给谁

- 想自建内部 AI 助手的企业 IT
- 金融 / 制造 / 政企等合规行业
- AI 服务商（作为定制交付底座）
